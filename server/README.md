# The server application for [scheda-informationis](https://github.com/JRD-HTLWY/scheda-informationis)

All tickets are saved to <> in a json-array in the following format:

```json
{
  "id": {
    "title": "STRING",
    "status": "INT",
    "description": "STRING"
  }
}
```


Technologies used in this project:
- wxWidgets
- make
- JSON
- CMAKE
- jsoncons
- asio
- C++
- wxFormBuilder
